RAG Chatbot - Quick Start Guide

What is RAG?
RAG stands for Retrieval-Augmented Generation. It's an AI technique that combines information retrieval with text generation to provide accurate, context-aware answers based on specific documents.

How Does RAG Work?
1. Document Processing: Your uploaded documents are split into smaller chunks
2. Embedding Creation: Each chunk is converted into a vector (numerical representation)
3. Vector Storage: Vectors are stored in a database (ChromaDB) for fast retrieval
4. Query Processing: When you ask a question, it's also converted to a vector
5. Similarity Search: The system finds the most relevant document chunks
6. Answer Generation: Groq's AI reads the relevant chunks and generates an answer

Key Components of This Chatbot:

Groq API:
- Ultra-fast LLM inference engine
- Powers the AI responses
- Uses llama-3.3-70b model by default
- Provides accurate, contextual answers

ChromaDB:
- Open-source vector database
- Stores document embeddings locally
- Enables semantic search (meaning-based, not just keyword)
- Fast and efficient for document retrieval

TOON Optimization:
- TOON (Token-Oriented Object Notation) reduces token usage
- Saves 15-30% on API costs
- Maintains answer quality
- Uses compact data format instead of verbose JSON

Embeddings:
- Uses sentence-transformers/all-MiniLM-L6-v2 model
- Converts text to 384-dimensional vectors
- Enables semantic similarity matching
- Runs locally on your machine

About the Technology:

Groq:
Groq provides the fastest LLM inference in the industry. Their custom silicon chips enable real-time AI responses at a fraction of the cost of traditional GPU-based solutions.

ChromaDB:
An AI-native open-source embedding database. It makes it easy to build LLM apps by making knowledge, facts, and skills pluggable for LLMs.

TOON Format:
A token-efficient data serialization format designed specifically for LLM contexts. It reduces token usage by 30-60% compared to JSON while maintaining full data fidelity.

LangChain:
A framework for developing applications powered by language models. It provides tools for document loading, text splitting, embeddings, vector stores, and chains.
